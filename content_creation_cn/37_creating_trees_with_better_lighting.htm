提高树的光影效果

  • 使用 mungenormals脚本

此部分只适用于不使用 SpeedTree 的客户。

由于树的建模方式特殊，因此是最难正确照明的对象之一. 大多数树都使用一系列由分枝向多个方向张开的面片构成。 这些??法线(用于照明)指向多个方向，因此不能营造整体,正确的光影效果。

3D Max 7 具有编辑法线修改器，它允许用户手动更改每个顶点的法线。 手动更改每个顶点法线将需要很长时间，因此，我们创建了允许用户只需单击即可编辑多个顶点法线方向的 MaxScript。

在下面的示例中，我们可以看到没有 编辑法线时，树在游戏中的照明不正确，虽然太阳光来自图片的左侧，但右侧的某些树枝被完全照亮，而左侧的某些树枝则处于阴影中。 请注意，右侧图片中的蓝色线表示法线方向.

在下面的示例中，我使用了 MaxScript mungenormals.ms 编辑该模型的法线，使它们从树的内部指向外侧（请看绿色线）. 这样就可以使树的光影效果,当太阳在头顶变换时, 正确渲染了. 你可以查看下左图, 左边为亮部, 右边是阴影.

下面的树是不需要进行法线编辑的示例。 所有广告板都从主干朝向外侧，因此所有法线都围绕树干散发指向天空。 这样当太阳在头顶移动时，树的光影显示正确.

使用 mungenormals脚本

请按照下列步骤使用 mungenormals 脚本:

1 将 mungernormals.ms MaxScript 从 bigworld\tools\misc\ 文件夹复制到 3dsMax\scripts\ 文件夹中.

mungernormals 脚本的工作原理是：将所有顶点法线从选定对象散发. 我们在树的中心位置添加一个dummy，让法线从此位置向外发散.

2 将Edit Normals修改器应用于您要运行此脚本的对象. 该编辑器应为此编辑列表的最后一个，因此，如果如下图所示为树设置动画，那么，请将该修改器添加到Physique / Skin修改器后面.

3 如果您无法看到如上所示的蓝色法线，那么，您可能需要增加 Edit Normals 修改器参数部分中的 Display Length.

4 选择 Edit Normals 修改器的 Normal 子组件，并以选取框方式选择要使用 mungernormals 脚本更改的所有顶点法线.

5 从 MaxScript 菜单中选择“Run Script”，然后在 Choose Editor File选择 mungernormals.ms 脚本

6 In the the Choose Editor File dialog box, select the mungernormals.ms script, then click the OK button –3D Max 中的光标现在将变成选择指针.

7 选择树中间放置的虚拟物体(您可能必须放大才能看清楚),所有顶点法线都应从该虚拟物体向外张开.

8隐藏虚拟物体dummy，并在选则 Edit Normals 修改器的情况下导出模型。 现在，您的树应在游戏中得到正确照明。

注： 如果为树设置动画，则需要自定义的 BSP。 请阅读课程创建自定义 BSP。
