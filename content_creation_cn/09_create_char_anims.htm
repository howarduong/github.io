对 BigWorld 引擎中使用的角色进行建模并创建动画时,应使其面向后视图. 因此,如果您从前视图观看模型,角色将背对着您. 3ds Max 和 Maya都这样.

如此设定角色的朝向是很重要的, 这样可以省下很多有意义的时间, 并减少当合并动画到游戏中可能出现的问题.

如果在角色做了骨骼绑定和动画之后发现朝向问题,再使用旋转和缩放来调整是非常容易出错的. 所以我们强烈建议在工作开始前做好正确的设定步骤.

在 Maya、3D Max 和 Fantasy Demo 中建模面向后视图的角色

如果你不习惯使用后视图编辑模型, 只要调整视图切换的快捷键就好了. 把原正视图的F设定为后视图的快捷键.

如果你现有的完成的文件是面向正视图的, 那么在导出的时候只要使用 Opposite Facing 功能,那么在BigWorld引擎中角色就可以正常运动了.

动画中根节点必须有位移

3D Max 和 Maya 中根节点的平移用于平移游戏中的对象。 因此,如果您希望角色或 NPC 在游戏世界中移动,则必须能在 3D 应用程序中移动。

创建动画时角色必须有位移

Biped 和其他节点部件都要离开原点运动, 以便导出– 不要在原点做动画.

不要在原地位置上创建动画

如果根节点不移动,那么,角色在 BigWorld 引擎中将不会移动.

Root Node根节点的线性运动

在 BigWorld 引擎中,对象的速度源于对象根节点的平移. 由于 BigWorld 服务器的优化需要,每个动画,根节点要以线性速率移动非常重要.

这意味着对象Biped的水平前后方向移动只能有两个关键帧,即,一个开始关键帧和一个结束关键帧。 对于非平移关键帧,允许任何数量的关键帧,例如,根节点可以左右移动,也可以上下移动。.

所允许biped的中心移动方式 － 只能垂直和水平方向移动

为了确保 3D Max 两足动物进行线性移动,请删除第一个和最后一个关键帧之间的所有水平关键帧.

选择并删除中间的身体水平移动关键帧,但保留开始和结束关键帧.

删除中间的水平关键帧,只留下开始和结束关键帧.


这将使得Biped从开始到结束一直呈线性移动, 这样玩家的角色可以同步模拟服务器上角色的位置.在它整个动画过程中, 根节点只能在垂直(z轴)和左右(x轴)方向上做非线性运动.

非biped骨骼的运动也一样要遵循此规则. 从开始位置到其结束位置,根节点都必须以线性速率移动.

上图中的根节点运动是不被允许的. 角色会卡在地面或穿过地面. 而且这样的运动,会导致客户端和服务器端的角色位置不统一

这种运动是被允许的, 模型的位移可以和服务器上实体的同步.

Maya 中的动画也一样,角色根节点必须沿既定行进方向线性移动.

只需记住中心节点必须随开始和结束关键帧之间的线性切线平移.

同步融合过渡动画

起始位置

起始位置,大多数动画中最好保证第一帧时根节点的坐标为(在3dsMax 用X=0 Y=0 , 在Maya中用 X=0 Z=0). 这样便于动画过渡衔接.

位移移动性质的动画

当一个动作 action被标为 IsMovement-匀速运动 过渡到另一个匀速运动, BigWorld引擎会自动在连接点上同步它们的衔接.

举例 1. 下图示例说明了一个 30 帧的行走动画 (蓝色) 过度到一个 30 帧的跑步动画 (红色). 在过渡到跑步动画时, 行走动画正巧完成了一轮. 这种情况下,从走到跑的 脚步位置效果是最好的.

举例 2. 此变化发生在行走动画到周期的一半(15帧). BigWorld引擎自动过度新的跑步动画时,智能调节到以跑步循环中位帧(16帧) 来完美过度行走动画.

举例 3. 当跑步动画的帧数总量是行走动画的一半量时. BigWorld 还是会很智能的做好动画间的过度, 通过找到动画周期相对应的节点(15/2 = ~8) 相当于第8帧, 并使用此帧做过度动画的衔接帧.

 

要达到这些效果, 需要动画师遵循一个简单的规则.

确保每个动画是一个循环的动作, 所有的将要用来衔接的动画必须满足, 动画的起始/结尾帧为相同姿势系列.

所以, 如果第一帧的行走动画是左脚向前的, 那么第一帧的跑步动画, 也要是左脚向前的.

为了确保动画自然过渡到另一个, 一般建议用idle动作作为起始帧, 并按照动画的延续性逐步按照一定帧数将起始动作做调整. 而不是把每个动画的姿势都吻合. 当创建走, 小跑, 跑的动画时, 按下图对起始帧姿势做逐步变动(约2帧后移), 在引擎中的融和效果会更真实,连贯.

简单图解如何设置 Idle, Walk, Jog, Run 的起始帧, 能达到更好的过渡效果.

 

转身动画


在创建左转和右转动画时, 最好把起始帧姿势设置idle的起始动作, 这样方便连贯,也就是说idle的起始帧,和转身的起始帧一样就好.

转身的结束帧姿势和idle的第一帧也要一样,但是根节点旋转了90度. 对于根节点应该没有在前后方向上的位移改动.

模型位置:
请时常检查,并确保角色的根节点的位于世界坐标中心位置, 也就是3dsMax中 X=0 Y=0, Maya中 X=0 Z=0.

 

下落动画

在创建一个下落动画的时候, 不要移动角色根节点的位置. 模型的下落动作是在原地模拟的. 而角色的下落位移是由游戏代码完成的. 和动画对应的下落动作, 需要勾选 下落. 标签

死亡动画

死亡动画一般会被分成两个部分: 从整体上来的一个死亡动画, 以及一个对死亡动画最后一帧做一个重复.

在你的3D软件中制作好一个死亡动画, 然后到模型编辑器里, 导入动画到动画animation tab标签下,两次, 把第二个动画命名为death:endframe.

第一个动画需要完整播放.

第二个动画只播放最后一帧.

创建两个死亡 动作, 一个是完整动画,一个是仅播放最后一帧的动画.

动画帧率

我们建议 BigWorld 引擎中使用 30或以上 帧/秒的帧率.

低于30帧每秒的动画是达不到良好视觉效果的. 记住, 动画在BigWorld引擎中是自动压缩的. 所以你尽可以制作高帧数的动画,然后在模型编辑器中调整压缩强度就可以了.

在3ds Max中设置FPS请通过 打开 Time Configuration 对话框.

在帧率Frame Rate 下, 选择自定义 Custom

设置 FPS 为 30.

在 Maya 中设置的方法是, 点击打开 Animation Preferences 对话框

设置 Playback Speed为Other, 再输入 30 到 Other Speed 定义框中.

动画范围

在3ds Max 的动画范围是通过在 Time Configuration设置起始时间 Start Time和结束 End Time 来控制的.

看下例, 如果你仅需要导出动画从 75 到105, 要在 Animation 下设置

设置 Start Time为75.

设置 End Time 为 105.

在 Maya中导出器读取 Playback Start Time 到 Playback End Time.

任何在此范围之外的动画信息将不被读取.

只有存储在帧 1 到 帧 10 之间的信息才会被导出

反转朝向Opposite Facing Direction

主角和NPC都应该是背对相机的, 如果一个角色在绑定骨骼时使用了对BigWorld来说错误的朝向,(比如面朝正视图), 就可以使用我们新添加的反转朝向功能.

我们假设一个角色朝向错误, 使得面向正视图. 如果只是在3d软件中旋转它的话,经过测试证实会出现一个窘境.然而, 如果角色已经被导入游戏,单纯选装其根节点又会导致它其他动画不协调.

为了修复角色朝向出错的问题,我们可以这么做:

1导出 .visual 文件, 勾选 Opposite Facing Direction;

2导出 .animation 文件,勾选 Opposite Facing Direction;

 

现在角色的朝向和其相关动画都将在游戏中表现正常.

自定义角色装备设计

很多游戏, 需要高度自定义的主角和NPC 模型,此章节会介绍一些在制作自定义角色时需要的技巧.

超模

一个超模就是一组由不同的, 独立的 .visual 模型文件, 装备在一套骨骼上的. 一个Fantasy Demo中的简单范例就是fantasy demo 中的參考角色Warrior . 每个 warriors 的装备都是绑定在和warrior 基础模型的同一套骨骼上的. BigWorld引擎会简单的下载多个模型，然后附和道同一套骨骼上。

下面的截图显示了各个独立的模型是如何整合在最后的超模上的.

 

以自定义角色为目的的超模在模块会跟随角色动画变形的情况时使用效果最佳， 如果只是静态的连接在角色身上，或者说和角色的动画没有相关联的，同步的关系， 只需要通过一个 Hard Point来连接模块就好了。

当你在3d软件中创建超模时,只要在一套骨骼上绑定多个模型对象, 然后分开导出就可以了.

在模型编辑器中可以预览多套的模型, 你可以通过菜单File - Add Model(文件 - 添加模型) 或者 按Ctrl 键, 从Asset Browser拖拽对象到视图就好了.

 

通过HP所连接的父级模型动作触发器，出发子级模型动作

 

虽然 Hard Points 通常有静态对象连接, 不过有时通过Hard Point来添加一套完全动画的对象到玩家模型上也是很理想的.

通过父级模型的action matcher 播放由HardPoint 节点连接物体的 "发动着的" 动作. 简单的说, 你可以附加一个斗篷或者马尾辫到父级模型的HP上, 并通过角色的 Action Matcher 播放其模型自带的动作.

如果你想要马尾辫的左右摇晃和角色的跑动步伐同步吻合, 你需要和主角模型 syncrhonise the animation同步动画 .

 

要启用动作匹配器来驱动所连接的物体,必须利用python代码做一些修改. 你如果你想确保这些功能的实现,请先找程序来做以下修改.

1. 添加一个动作匹配器驱动到你所连接的模型(例如, staff/手杖) 然后设置它 useEntityModel 的属性为True.
2. 设置 $p.model.moveAttachments 为 True

要在Fantasy Demo 中实现这些功能预览, (目前的FD尚未自动加载这些设置), 取出staff并输入如下命令在python控制台下:

am = BigWorld.ActionMatcher( $p )
am.useEntityModel = True
$p.model.right_hand.addMotor( am )
$p.moveAttachments = True
$B.debugAQ( $p.model.right_hand )

然后你就可以看到手杖的动作被ranger所驱动了.

 

注意: 如果你的动作速度是要缩放的, 那么其通过HP连接的对象的动画也需要允许缩放, 即"勾选缩放重播速度". 请參考 模型 staff.model 作为案例.

在FantasyDemo中, 玩家拿的 staff.model 模型有通过主角驱动的自己的动作.

如果要预览staff模型的动作, 进入 python 控制台 (Caps +P)

输入 $B.debugAQ($p.model.right_hand)

 

请注意staff模型动作是如何根据玩家动作反应的.

 

 

如何修复顶点法相接缝

当你在创建一个超模的时候， 通常会出现两个模型交接在一起的现象， 当模型被切割为两个独立对象时，他们的边界（切割处）的顶点法相通常和相邻的对象的顶点法相不一致。 结果导致了两边的色差相遇出现接缝， 下图中很明显的看到两个相邻模型的接缝，成因是接缝顶点法相的不一致。

切割物体后的光影接缝

不过还好我们可以利用max中的编辑法相功能，edit normals， 来修正顶点法相，在Maya中的相对功能是 Vertex Normal Edit 工具。

通过法相编辑工具修正顶点法相。

对于 3dsMax:

1. 选择两个你需要修改法相的模型Select both assets you wish to consolidate vertex normals

2. 添加一个编辑器 Edit Normals

3. 选择模式为 Normals

4. 平均所选择的 Selected 法相

5. 导出时请保留编辑器独立, 不要塌陷

6. 确保在导出时,每个对象单独导出使用 export selected, 同时在导出器选项面板中勾选 normal mapped就好了.

 

 

对于 Maya:

1. 使用功能Lock Normals 锁定相邻法相 --- Normals > Vertex Normal Edit Tool

2. 确保每个模型单独导出,选择 export selected, 并且模型导出时勾选 normal mapped.

 

参考层级关系/自定义辅助工具对项

use Reference Hierarchy

选项允许动画师调用一个不同的层级关系到一套以默认层级关系导出的模型上.

例如, 如果你需要一个特殊的动画, 使用一个根节点位置在手上(角色挂在树上)会比一个根节点在默认跨部中心的要方便的多. 那么你就需要用到参考层次关系Reference Hierarchy 功能了.

如何使用参考层级关系:

1 默认的层级关系(以跨为根节点)在导出时不需要做任何改动. 这个visual文件会被用作被参考的层级.

2 另存一个3d备份文件.

3 调整3d文件的层级关系(手部为根节点).

4 模型通过新的层级关系制作动画 (手部为根节点).

5 导出动画时勾选use reference hierarchy. 此项被勾选后,会有一个相应对话框弹出,要求参考层级的路径位置. 只要选择原始那个在第一步中导出的visual文件就好了.

 

使用参考层级功能来去除不需要的控制杆

此例的目的是要求在导出动画到BigWorld时,不要携带不必要的信息(例如 控制杆 handles 和 controllers, 它们会在游戏中被渲染). 所以, 我们需要导出一个没有携带此类信息的 visual文件. 而相应的animation 文件,也应该只携带动画数据.

 

  • 打开场景文件.
  • 场景中包含了我们在制作visual文件时并不希望被导出的dummy/controller等工具.这个场景还包含了一个动画变形的目标模型,是一个在弯曲时的二头肌变形. 会在手臂弯曲时,由Set Driven Key 触发.我门们不需要担心目标变形动画, 因为在我们保存此场景文件时并不需要导出此变形. 然而这样的弯曲信息必须保留在所有的场景中.
  • 删除那些场景中的在导出不需要的 controller 物体.

  • 另存一个只包含骨骼和变形目标的新场景.
  • 在 File/Export All 菜单下选择 Bigworld Asset 格式导出. 保存这个基础 .visual 文件, 类型勾选animated,skinned.
  • 在前一个包含控制杆等对象的场景中导出 File/Export All 格式为"Animation". 切记勾选 "Use Reference Node".
  • 一个新对话框会弹出要求你选择基础文件, 你只需要选择之前导出的 .visual 并点击 " OK".
  • 在世界编辑其中打开你导出的.visual 和 .animation. 如果你按照正确的步骤操作. 你将会得到一个干净的动画场景, 没有任何不需要的对象.

添加Node tracks节点轨迹来触发事件和声音

节点轨迹只在 3dsMax 中可以实现. 如果你使用的是Maya, 请參考章节 splitting up actions

节点轨迹是一个在某一动画的特定时间插入信息的方法, 这样一些事件,比如声音和特效就可以被触发了.

要添加一个节点轨迹, 在3d视图中选择你需要添加轨迹的节点.

打开 Graph Editors - Dope Sheet

你就可在3d视图中看见选择的节点.

节点轨迹notetrack必须直接添加到一个节点上. 整个场景或者针对某些深度参数节点的轨迹(例如,变形或者材质)会被忽略.

一旦选择了你想要的节点,就通过菜单操作 Tracks - Note Track - Add

在摄影表-dope sheet下, 右键点击note可以编辑参数内容.

BigWorld引擎会识别下列输入

cue:name

sound:name

替换 name 为你需要触发的事件名称. 记住在整个命令中没有空格, 语句以回车结束.

例如: sound:ui/boop 的参数可以触发声音事件 "ui/boop"

当你要导出这里动画时,请勾选 "Export cue track"

这些节点会触发一个回调函数, 程序可以使用它来创建特效.
