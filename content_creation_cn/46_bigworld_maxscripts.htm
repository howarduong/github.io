BigWorld MAX脚本简化了一些 BigWorld 资源创建的特殊任务.

安装

拖拽 BigWorld_MAXScripts.mzp 文件到 3dsMax 的3d 视图中。

重启 3dsMax.

 

到目录 Customize - Customize User Interface

 

选择 Toolbars 面板并创建一个新的工具栏 toolbar. 命名新工具栏为 "BigWorld"并点击 OK 确认.

 

一个新的浮动工具栏会显示在3d视图中， 拖拽窗口到目录栏上以免影响视图。

 

返回到 Customise User Interface设置 - Toolbars 工具栏面板. 在 Category下 BigWorld 组中 拖拽可用的脚本到 BigWorld 工具栏上。

 

现在你的工具栏已经可以被使用了。

 

添加自定义壳

更多关于 自定义壳的信息请参见位于 bigworld/doc/content_creation.chm 的创建工具手册。

点击添加自定义壳图标 会转化选中的对象为 自定义壳, 对象的名字会显示为带后缀 "_hull". 一个自定义壳的材质会被赋予对象以方便视觉识别。

壳的多边形可以通过其他脚本被设定成为portal门.

添加入口属性

更多关于portal的信息请参考 bigworld/doc/content_creation.chm 内容工具创建手册

通过点击添加门的按钮，脚本会自动指认一个门的属性到选择的对象。

添加一个标准的门 portal 标志

添加一个出口 portal 标志

添加一个天窗 portal 标志

portal入口的指认会添加一个材质道选择的对象上以方便识别. 材质被存储于位于 bigworld/tools/maxscripts/resources/materiallibraries/ 的文件 BigWorld_MaterialLibrary.mat 中。

有两种方法可以用来使用这个脚本指派入口.

1. 整个对象 (一个平面) 可以标示入口标记, 通过使用自定义属性 "portal = true"。

2. 或者，如果选择一个自定义壳的次级对象多边形, 然后那个面会被赋予入口材质.

倒入HP节点

更多关于Hard Point （HP）节点的信息请参考 bigworld/doc/content_creation.chm f 内容创建工具手册

当多个美工在创建相互关联的资源时 (例如，一把枪和一个角色的手), 会出现HP位置的不一致问题。 这个脚本可以降低行列不齐的几率。它可以标准化HP的模型和其对其父级节点的方式。

点击按钮倒入HP节点 会自动创建并连接一个标准化的HP模型到所选物体。

如果没有选择对象， 新建的HP会被赋予到世界中心原点 (0,0,0).

这个表示Hard Point 的模型会自动缩放，所以它在场景中总是约等于20c厘米无论你的系统unit设置为多少。此模型是一个 BigWorld 管理系统的代表。

这个hard point 模型 hard_point.fbx 被安装到 3dsMax's 项目project 文件夹内:导入文件夹并使用 BigWorld_MaterialLibrary.mat 中的材质。

 

添加一个节点轨迹

更多源于节点轨迹的信息请参考 bigworld/doc/content_creation.chm 内容创建工具手册

点击按钮添加一个节点轨迹 会允许用户快速添加一个类型为 cue 或者 sound 的节点轨迹到当前时间的所选物体。

标记为 BSP (碰撞体)

更多关于BSP 碰撞体的信息请参见位于 bigworld/doc/content_creation.chm 的创建工具手册。

点击转换 BSP 按钮 可以转换任何几何体对象为一个 BigWorld BSP碰撞体. 被选择对象的名字会被添加后缀 "_bsp" , 同时一个材质会被自动添加到对象上，以方便在 3dsMax 中识别BSP物体。
