导入一个新的角色

从3ds Max 和 Maya 导出角色到模型编辑器,參考以下步骤 :

1 打开 ModelEditor.

2 选择 File→Open Model 或者按 Ctrl+O 打开文件浏览器.

3 指认到之前导出的模型, 点击 Open..

在浏览器中选择Ranger 模型

或者你也可以使用 Asset Browser– 选择 Assets 标签, 输入想查找的模型名字在搜索栏. 使用虚拟文件夹分开对象类型shells, particles, 和 models. 一旦你找到需要的对象,双击在预览视窗打开.

4 对象在预览视窗打开.

在视图中显示Ranger模型

5 你可以通过创建缩略图 Create Thumbnail () 按钮刷新预览图.

图片以 JPEG格式保存在同文件夹下

给模型添加动画

在模型编辑器中给模型添加动画, 參考以下步骤:

1 选择 动作 标签.

2 点击按钮 打开

在下例中, 所有的动画都是由LOD模型导入ranger的. 模型可以通过LOD来共享动画. 关于LOD动画的更多信息,可以查看章节 Animation tree – Using LOD models to share animations.

3 打开 对话框, 调用需要的动画 .animation 文件

如果骨骼的父子关系以及命名和visual文件一致的animation动画就可以在模型上调用

你也可以通过从 Asset Browser拖拽动画到animation 动画窗口下来添加动画.

从 Asset Browser 面板拖拽动画

预览动画和查看帧率

通过 play播放和 stop停止 控制当前选择的动画预览. 在面板中可以通过其他选项调整动画的播放效果.

Current Frame当前帧 的滑块可以用来调节播放的帧,与3ds Max 的类似. 还有 Frame Rate帧速率 滑块, 用来调节动画的速度. 帧率是可保存在动画信息中的, 而游戏中会显示修改后的动画.要保存修改,必须点击按钮 Save Frame Rate[保存帧速率].

循环播放动画按钮Loop Animation () 会不停的播放选择的动画, 是检查动画的一个很有用的方式. 请注意,这个选项不影响动画在游戏中的播放 – 只是一个预览功能.

你可以设置Include Frames限定帧数 中的第一和最后一帧. 这可以手动定义哪些帧动画需要被剪切掉.

 

逐节点动画的叠加

在BigWorld引擎中,多个动画可以叠加后同时播放. 想要理想的叠加效果, 必须给动画中的每个节点(骨骼), 节点叠加的系数值在模型编辑器动画面板下编辑.

我们来比较一下这两个动画: holddrink_stand.animation 和 m_walk.animation, 他们在游戏结合时融和的非常好.ranger会一手拿茶杯一边走.

你可以查看下图的设置, 在holddrink_stand.animation 中一个重要的节点就是 右手. 如果你不使用这些节点, 那么动作会握不住手中的饮料. 为了突出右手动作的重要性, 我们将这些节点的权重,由节点biped R Clavicle 开始往下,都设定为 1.0, 同时腿部的节点 (对于动作 holddrink 没有关系的) 权重都设置为0.0.

动画 m_walk.animation 然而, 需要每个节点都有权重, 当一个角色走动时,几乎所有的骨骼都在运动.r

节点的叠加权重值,在单个播放动画时是无效的. 所以当一个特定节点在权重(节点混合) Node Blending 值下设置 0.01, 它的动作单个播放时,和你在3d软件中的无异.因为没有其他动作和它叠加起作用. 然而, 在另一个动作同时播放时, 这个权重值就会被识别, 并和其他的动作叠加出最后效果

Node Blend节点混合 数值为 0.0 是一种特别情况 – 如果节点被设定为0了,那么即使在单独播放动画情况下,也不会有任何动作被播放.

holddrink_stand.animation 动画的节点混合值

walk.animation 的节点混合值

并不是所有动画都合适叠加播放的, 我们美术人员试图要将 Stand_Shoot_gun.animation 与 Run.animation, 混合,可效果不能被大家认可, 新的动画很不自然. 所以只能手动创建一个新的动画 Run_withgun.animation

Actions动作 面板下的设置决定了哪些动画可以同时播放. 更多信息请參考Modify Animations with Actions.

 

Blend values greater than 1.0 can be assigned to a node to give it more weight when blending.

Its important to recognise that strong node blend values will effect the blend in and blend out times between actions. In the diagram below a node with a strong blend weight in Action A will still be the strongest influece at the time marker , if blending with a significantly less weighty node.

动画压缩

BigWorld 引擎自动压缩动画. 在模型编辑器中可以调节强度.动画师可以通过ModelEditer下的预览工具做调节.

动画的压缩对于游戏效率很重要. 这样也可以让动画制作中使用更高的帧率和精确度.每个动画加载到模型编辑器中时,都会被默认压缩.默认压缩率采用对于视觉表现损耗最低的一个设置. 尽可能在最大压缩后不影响视觉效果. 80%的动画压缩只要采用自动默认设置就可以了. 虽然我们强烈推荐自动压缩模式, 但是没有什么比一个动画师的眼力更有效, 我们建议对于每个动画都由他们略作预览和调整, 这样可以得到更好的压缩效果和游戏效率

按下述步骤做动画压缩调节:

1 在模型编辑器中打开模型.

2 在动画标签下, 选择你想要压缩的动画

3 在Compression Settings压缩工具栏 点击 显示原始动画线框

4 加调整压缩比例预览时发现在0%压缩率时,线框动画和角色动画完全贴合. 当加强压缩率后位置出现差异, 这时通过动画时的眼力判断最合适的设定.通常在线框隐在角色模型内的时候是比较好的.

不用担心动画信息因为压缩而丢失, 压缩不会覆盖动画的原始数据文件-所有压缩结果都保存在独立的.anca 文件中, 原始的l .animation 文件完好无缺. 如果你觉的80%的压缩率抬高, 你可以很简单的调节到70%, 而不用重新导出动画.
