首先申明 Speed Tree CAD 是BigWorld的一项非强制组件. 它并非BigWorld名下的工具.

关于speedtree的功能介绍远不止这篇教程. 所有关于如何使用speed tree, 并且创建你自己的树的文档请参考它的相关工具所附带的文档资料.

在世界编辑器中添加speedtree

SpeedTrees 的资源文件可在世界编辑器, Asset浏览器下, Tree 虚拟文件夹下面找到.

只要从资源浏览器拖动你想要的树到世界,就可以了, 或者你选择好想要的树文件, 移动光标到合适位置,再按回车键.SpeedTrees 可以移动,缩放,旋转,就和多数的其他模型一样.

在放置树的时候, 最好记得使用锁定方式中的地形吸附模式, 这在工具选项:对象面板中选择.

高光反射

通常树叶的高光反射都比较弱, 并且因为叶子的形状,也只在半边叶子上表现.

高光贴图在speedtree叶子上的效果可以通过手动修改叶子的法向贴图来显著提高.

树的高光一般比较弱,并且主要发生在半边上

1 为了理解树叶的normalmap, 我们要首先创建一个色彩盘. 在photoshop工具中创建一个中心辐射渐变的原型

3 使用工具 Nvidias Photoshop Plugins 把原本的黑白图形转换为normalmap

4 现在可以使用转变好的normalmap做参考,手绘我们的树叶normalmap了.

5在photoshop中打开树叶贴图,根据分析,在色盘上选择最能表达树叶朝向的颜色,手绘normal.

6画的时候要超过叶子的外边界, 这样可以保证给我们一个漂亮平滑的高光效果.

防止贴图空间的浪费

SpeedTree 在创建整合贴图的时候, 它把独立的贴图拼合到一张上去,并试图使用最小的空间. 有时候创建出的贴图浪费了大量的贴图空间, - 这常常因为贴图的不规则尺寸和形状而发生.下例中,通过调整 frond贴图尺寸使得拼合后的贴图可以整合到一张 1024x1024 的贴图上.

Billboard 数量和贴图尺寸的使用

多数在FantasyDemo的中的SpeedTrees使用了6个纵向,1个横向的billboard. 每个为128X128像素大小.

对于一些很大的树和树丛, 我们建议你可以先测试现有billboard的效果, 并从个个角度观察, 如果他们看上去不对, 那么就可以通过增加贴图数量和尺寸来调整.

Billboard 的光效

如果你使用了带normalmap的billboard. 记住在导出时勾选 Uniform lighting 选项.这是为了保证没有任何方向性光源信息烘培到你的billboard压缩贴图上.

 

定义树的碰撞体

SpeedTree的碰撞体是在SpeedTree Cad中定义的 – 要查看碰撞体,要点击按钮下拉菜单 Toggle Collision Objects () , 选择形状创建.(下例中我们选择了添加Box)

调整box的位置形状,使它和数目切合. 避免使用球体,立方体在游戏中比球体有效多了, 记住使用越少的面越好.

没有对树干做碰撞体的必要, BigWorld会自动对树干模型做自身碰撞的.

在做叶子的时候要注意碰撞体的位置, 如果太低了,角色会撞到.

这个你可以在BW世界编辑器中查看在speedtree中定义的碰撞体,和树干的自身碰撞, 你在 Options 面板 Show 组下勾选 Scenery→BSP 就可以看到下图的bsp

 

SpeedTree 的LOD

 

SpeedTree 的 (LOD) 设置可以在文件 speedtree.xml 中修改, 位于bigworld\res\system\data\speedtree.xml

在speedtree.xml 中的多数参数是可以修改的. (但仅供预览) 方法是在client运行时,使用快捷键 Caps + F7到13 [SpeedTree]下.

 

speedtree.xml 文件的大致内容如下. xml 文件中的注解解释了这些参数是如何影响speedtree的.

<speedtree.xml>
	<lodMode> -2 </lodMode>
	<!-- lodMode to use:
		-1: dynamic (near and far LOD defined per tree using speedtreeCAD defined values);
		-2: dynamic (use global near and far LOD values);
		[0.0 - 1.0]: forces static value.
	-->
	
	<lodNear> 40 </lodNear>
	<!-- Distance from camera at which trees will start 
		to display maximum detail. Only used if lodMode is -2 -->
		
	<lodFar> 200 </lodFar>
	<!-- Distance from camera from which trees be rendered 
	as billboards only. Only used if lodMode is -2 -->
	
	<lod0Yardstick> 60 </lod0Yardstick>
	<!-- Trees taller than the yardstick will LOD to billboard farther than LodFar.
	Trees shorter than the yardstick will LOD to billboard closer than LodFar.
	This should be set to average the height of your trees-->
	
	<lod0Variance> 0.3 </lod0Variance>
	<!-- How much will the lod level vary depending on the size of the tree -->
	
	<speedWindINI> system/data/speedwind.ini </speedWindINI>
	<!-- Global SpeedWind setup file -->
	
	<fxFiles>
		<branches> 		shaders/speedtree/branches.fx 	</branches> 
		<leaves> 		shaders/speedtree/leaves.fx 	</leaves> 
		<billboards> 	shaders/speedtree/billboards.fx </billboards> 
		<shadows> 		shaders/speedtree/speedtree_shadows.fx </shadows> 
	</fxFiles>
	<!-- Effect file used to render trees -->
	
	<billboardOptimiser>
		<fxFile>	shaders/speedtree/billboards_opt.fx	</fxFile>
		<enabled>	true </enabled>
		<textureAtlas>
			<!-- The optimiser will create one big 
			texture to hold all billboards -->
			
			<minSize>	128	</minSize>
			<maxSize>	2048	</maxSize>
			<mipLevels>	7		</mipLevels>
			<!-- 
				2^(mipLevels-1) should not 
				be greater than minSize
			-->
			
			<save>			false	</save>
			<!-- If true, will save the texture atlas into a file called 
			bboptimiser.dds, in the current work dir. This can be useful
			for debugging and also to tune the ideal parameters of the 
			texture atlas. The file will be resaved for every new tree 
			type read from disk. So, make sure all tree types have been 
			loaded before making any decision based on this file. -->
			
		</textureAtlas>
		
		<buffers>
			<framesToRecycle>	5		</framesToRecycle>	
			<!-- number of frames before a buffer is 
			made available for reuse by a new chunk -->
			
			<framesToDelete>	100	</framesToDelete>	
			<!-- number of frames since last time before a 
			buffer is permanently deleted -->
			
		</buffers>
	</billboardOptimiser>
</speedtree.xml>

SpeedTree 和风效

SpeedTree 所创建的树是会受世界风的影响的. 而控制它受影响的文件是位于bigworld\res\system\data\下的 speedwind.ini文件. 它是一个全局控制文件.

如果你想要每棵树有不同的风效影响,那么就要在每个树的目录下建议一个独立的 speedwind.ini 文件. 但是这种做法会影响游戏效率.

speedwind.ini 文件中下列属性的描述,可以参见SpeedTree CADs 使用者参考文档中以SpeedWind 开头的资料

 

NumWindMatricesAndLeafAngles 6 8
WindResponseAndLimit 0.4 0.01
MaxBendAngle 70
BranchExponent 3
LeafExponent 0.8
GustStrengthMinMax 0.1 0.5
GustDurationMinMax 2 5
GustFrequency 0.166667
BranchOscillationX_LaLsHaHs 2 3 15 4
BranchOscillationY_LaLsHaHs 1 3 65 3
LeafRocking_LaLsHaHs 1 4 5 15
LeafRustling_LaLsHaHs 2 4 5 10

 

这些设定在和在 SpeedTreeCAD 中的编辑 SpeedWind 参数是一致的。


对于speedwind.ini 文件的修改也可以通过client客户端监测预览.Caps+ F7 - Client settings - Weather - WindVelX and WindVelY
