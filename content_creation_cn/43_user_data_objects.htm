UDOs (User Data Objects) 是指可以更具各项目被自定义的对象.

他们允许使用者放置游戏逻辑信息到世界中去. UDO还可以互相链或者和其他实体链接. 比如, UDO可以用来定义玩家陷阱, 巡逻节点,和好的补位设置.

Entity实体是游戏的动态对象, 并可以通过脚本和UDO关联, 这些实体可以是客户端实体, 客户端-服务器端实体, 服务器端实体. 实例列举的话,这些实体可以是, NPC, 怪, 门, 任务物品, 车子, 重生点等.

UDO 的属性

如果需要,游戏的程序员可以自定义一些UDO来使用, 而且都可以被添加到BigWorld世界编辑器,资源面板- Asset Browser 面板下 User Data Object中.

我们无法在此教程中包含所有自定义的UDO的控制属性,所以我们就主要介绍一下在FantasyDemo中默认可用的一些功能.

UDO: CameraNode相机节点– 定义一个相机飞行通过的路径. 每一个路径上的节点用来控制那个节点的位置, 旋转,角度等信息.BigWorld Demo 的相机飞行脚本启动属性的名字是 "camera node0"

UDO: PatrolNode巡逻节点 – 定义卫兵的巡逻路线.
巡逻节点有很多有用的属性,可以通过属性面板编辑. 请参考下表(按照界面截图排序):
Property Description
departureSpeed

节点出发速度.

如果你想卫兵从节点跑开就设置一个比较大的值.
importance 重要性权重，在多个路径可选状况下, 实体通过此路径的几率.

行走路径的可能性是通过对所有可行路径 Importance数值总和计算比重决定的.

backtrackChange 卫兵在此节点返回的几率.
waitSecs 卫兵到节点后停顿的时间.
radius 节点大小 , 从一个节点到下一个节点的路上会经过的每个节点辐射范围.

PlatformNode平台节点 – 在线世界浮动平台的路径. 其属性包括:

Property Description
Approach Speed

平台节点到达的速度
Approach Acceleration 为了到达速度approach speed而使用的加速度值.
Wait Time 平台到达节点后的停留时间.

Entity : IndoorMapInfo室内贴图信息 –这个实体切换室外小地图为室内小地图, 一般将它放在室内(壳)的入口处,那么客户端就知道何时切换小地图了.

Property Description
mapName 指定小地图 (alpha)贴图的位置和名字
Position x,y,z

贴图中心点的位置
worldMapHeight,Width 小地图的世界的尺寸

 

放置 UDOs

默认的UDO都使用相同界面. 按照此手册的宗旨,我们将解释巡逻路径这个 UDO.

路径节点在世界编辑器中的添加方式和所有其他对象一样.例, 你可以从 Asset Browser 面板拖拽文件到世界, 或者选择对象按'回车键'.

新添加的节点会带有'加号'和'圆点'图标.选择并拖拽加号会自动添加一个巡逻节点并连接路径.

巡逻方向(就是从一个节点到另一个节点的蓝色连线方向)一般默认为指向新建的巡逻节点.

如果想更改方向, 选中节点间的连线,点击右键使用 Swap Link Directiom 反转链接方向功能.

你可以通过选择巡逻路径和和拖拽其圆形节点连接到卫兵实体上, 反之亦然.

现存的巡逻节点可以通过原型控制节点拖拽后连接到其他节点上.

使用 UDO 相机节点测试游戏表現

UDO节点中使用时有一个非常有用的功能,就是利用相机节点来测试游戏表现(帧数)

游戏效率图形化是一个强大的工具, 你可以通过它看到测试数据,从而进一步理解美术制作是如何影响到最终的游戏帧数的.

如果你想看看你的修改如何影响了游戏的表现,例如, 在加载了一套模型后,贴图更新后, 或者使用了一个新的材质后, 你可以通过运行游戏表现测试来比较变化前后的差异.

在此之前,你必须先设置好一系列的循环相机路线, 请參考小节 放置 UDO 中的介绍.

 

第一个设置的相机必须被命名为 "camera node0"

要做游戏表现测试必须先运行客户端 .

打开Python控制台 Python consol 使用快捷键 ~ (tilde) + P

输入 BigWorld.runProfiler ('camera node0',3,"nameofoutputfile.csv")

数字'3' 表示在飞行相机的过程中会重复几次, 通常, 我们使用飞行次数会超过1次, 并且忽略第一次产生的数据, 这是为了确保所有数据都在内存缓存后再给出真实的游戏表现指数.

上述命令相机开始飞行,并把帧数数据保存自动保存到一个 .csv 文件中去, 并保存在客户端可执行文件夹下 (fantasydemo/game). 这些文件可以利用页面展开程序直接进行比较, 例如 Excel. 或者你可以使用python脚本 caclstats2.py 来制作一个 .png 全局帧率图形文件.

要制作图形文件,你需要工具 python 2-5 并且安装一些python数据库 (numpy, matplotlib) .

复制文件 .csv 和 calcstats2.py到同一个共用文件夹, ( 我在此使用 C:/performance tests/)

windows系统, 开始 - 运行

输入 "cmd" 在打开位置

对 .csv 文件运行脚本 calcstats2.py

这就会生成一个叫做 "output.png" 的图形文件

 

此生成的图形文件显示了整个过程的帧率变化. 可以利用Photoshop软件叠加两个图片进行比较.
