使用导出器exporter

1启动导出过程.

选择 File→Export All 目录导出所有场景中的物体.包括隐藏对象.

–或者–

选择 File→Export Selection 目录导出, 当前选择的对象.

弹出导出对话框.

3 在导出器对话框中:

A 在 Look In 下拉列表中, 指定想要导出的文件夹.

B 在 File Name 下拉列表中, 定义你文件的名称.

C 在 Files Of Type 下拉列表中选择BigWorld Asset格式

D 点击 Options 按钮, 根据之前选择的 项目菜单 Export All Options 或者 Export Selection Options 对话框会调出.

在对话框 General Options中,设置File Type 下拉选择 BigWorld Asset.

点击 Export All 或 Export Selection按钮 (是根据之前选择弹出的) – 这会关闭当前窗口,并反回前步骤 Export.

E 点击 Export 弹出 Visual Exporter 对话框.

Visual Exporter 对话框中点击 OK 文件导出到定义好的位置.

使用 BigWorld shelf 定义portal

BigWorld Maya shelf提供工具来定义portal. 其中有三个图标, 分别用于, Portal, Exit, 和 Heaven portal 的类型.

三种图标:

– Portal flag

– Exit flag

– Heaven flag

要定义一个对象为 portal, 首先选择你需要的portal类型. 检查属性.

Extra Attributes 下的 Portal 选项卡 – 它会根据属性显示 Heaven 或者 Exit.

确认后就可以导出了.

在 Maya 中 制作 Hard Point 节点

这个篇章介绍了如何在maya中定义portal和创建 hard point. 但是此篇不能替代另外两课的内容, 创建角色LOD 和 创建室内shell – 这两个课程是必须学习的

HardPiont 要以 polygen的原型来创建 , 并且要方便辨识对象的 XYZ轴指向. 这样才能在合适的位置正确使用.

这里的 外形, 忒图和几何体,仅仅作为美工的视觉工具. Bigworld 引擎仅通过对象的命名 HP_ 来辨识节点属性. 其中包含HP所连接到的骨骼node.

此例中,我们创建一个连接在角色右手上的HP节点.

1创建一个合适的几何体

2选择菜单 Window → Hypergraph 菜单项目 – Hypergraph 窗口打开.

3右键点击node,选择 Rename重命名.

4重命名为 HP_RightHand.

5中键点击 HP_RightHand node, 拖拽到父级 RightHand 节点.

6 现在HP已经正确连接并且可以使用了.
