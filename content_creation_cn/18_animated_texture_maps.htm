贴图压缩设置

BigWorld支持这些贴图格式:

"dds", "bmp", "tga", "jpg", "png", "hdr", "pfm", "dib", "ppm"

这些贴图会在运行时自动转换为.dds格式

TGA (targa) 格式被转成 DXT3 格式, 而 BMP 格式被转成 DXT1 格式.

应为 DXT3 会占用相对 DXT1 相对两倍的空间, 请只有在带有alpha通道的贴图情况下使用tga格式.

任何有后缀 _ norms 或者 _normal 的贴图会被转换成 A8R8G8B8 贴图, 这是为了防止BigWorld 过度压缩法向贴图.

Texture detail levels.xml文件 - 定义压缩贴图

texture_detail_levels.xml 文件位于 fantasydemo/res/maps , 是用来定义全局范围内对于大量贴图的压缩定义, 可以通过所在文件夹或文件命控制.

例如, 项目中的GUI图像如果被过渡压缩而出现问题的话. 你可以通过定义 texture_detail_levels.xml 中,如下的这一段来防止过度压缩问题.

<detailLevel>
<! -- Defines the directory which compression rules should be applied -->
<prefix>gui/maps</prefix>
<! -- Files including the word "gui" -->
<contains> gui </contains>
<! -- Defines what file type should be compressed. Alternatives include tga -->
<postfix> bmp </postfix>
<! -- Defines what compression the defined file should use. Alternatives include DXT1, DXT3. DXT5 -->
<format> A8R8G8B8 </format>
<lodMode>1</lodMode>
</detailLevel>

贴图格式 - 贴图压缩

或者使用另一种方式来保证贴图压缩质量, 如果某个贴图被Direct X过渡压缩. 你可以强制它保留每个通道8bit的质量 (A8R8G8B8), 做法只要在同文件夹下创建同名文件.texformat (.texformat可以通过任何文本软件创建, 例如写字板 Notepad). 一般最好通过texture_detail_levels.xml 文件来定义方便画面的整体设置, 然而,总是会有一些例外情况,这时,使用.texformat 是一个更简单的方法.

那么假设下例中的 sky_gradient.tga 贴图被过渡压缩了, 通过创建 sky_gradient.texformat 并放在 sky_gradient.tga同文件夹下, 则贴图不会被压缩. sky_gradient.texformat 文件内容如下

<sky_gradient.texformat>
   <format> A8R8G8B8 </format>
</sky_gradient.texformat>
你也可以阻止使用 mipmap， 如果你在 texformat文件中添加标签 <noResize> true </noResize> 并且设置为true，那么引擎就就会被强制使用所提供的文件，而不去创建一个dds了， 不过此方法需要谨慎使用 。

贴图动画

创建贴图动画文件

要创建一个动画贴图, 请参考下列步骤:

1 使用任何你习惯的软件, 创建如下六帧的电场图片..

需要创建一个文本来播放这一系列的图片.

打开一个文本编辑器,例如 Notepad并输入如下脚本, ( 之后会被保为一个 .texanim 文件):

    <root>
       <frames>abcdef</frames>
       <fps> 30 </fps>
       <texture>texturepath/electric1.bmp</texture>
       <texture>texturepath/electric2.bmp</texture>
       <texture>texturepath/electric3.bmp</texture>
       <texture>texturepath/electric4.bmp</texture>
       <texture>texturepath/electric5.bmp</texture>
       <texture>texturepath/electric6.bmp</texture>
    </root>

对于.texanim 文件的语法解释如下:

<frames> 标签定义镜头的播放顺序. – 此例中一共 6 个镜头 (a-f) 连续播放

如果你需要第二帧和第五帧互换,那么排序方式就是 <frames>aecdbf</frames>.

如果你要延长第四帧,使它播放两次,那么,就变成<frames>abcddef</frames>

如果你想使用超过26帧的动画, 你可以不用 <frames> 分段, 贴图的播放顺序会按照.texanim 列表的顺序播放.

<fps>标签定义了动画播放速度, 此例中每秒30帧.

<texture>标签定义要播放的图片 – 文件要按顺序编号排列.

texturepath 应该用资源所在路径替换. 关于贴图路径的设置,请参考章节 资源管理.

保存的时候, 给它以贴图系列第一张同名命名, (但是存为 .texanim 扩展名) 和所有贴图资源放在同一文件夹中 – 此例中,文本被保存为文件 electric1.texanim 放在文件夹 texturepath下

应用动画贴图到模型材质上

按此步骤将动画贴图用到模型材质上:

1 打开模型编辑器.

2 打开你想应用动画贴图材质的模型文件

3 在材质面板下, 选择需要的材质类型.

4在材质属性表格中, 在diffuse map位置选择浏览按钮() 打开文件选择对话框

5 在文件浏览器中, 找到动画贴图所在的文件夹, (此例中是 <res>/texturepath), 选择texanim文件 (i此例中是, electric1.texanim).

6 所选择的动画材质可以通过各种默认模型预览. 要启用此浏览方式, 勾选 预览, 并在下拉菜单中选择想要使用的模型.

7 保存修改后的模型.

制作cubemap浮点立体帖图

cube map是一张集合了6个独立图片并整合其成为一个360度全景的贴图。Cube map在Bigworld中主要做为环境反射贴图使用. 使用 Cube Map可以让你见到相对与"raytraced"反射效果没有那么精密严紧的模拟"假反射 "

把Cube map放在反射通道上,可以模拟出带有克罗米反射效果的水面.

 

如何创建一个cube map:

创建六张环境贴图 ( 例如,上,下,左,右 ). 最好可以把它们都衔接起来保证无缝效果.

很多第三方插件可以很容易的完成这个任务.

使用图像编辑器确认图片是正方形,且边长为2的次方 (ie. 256, 512, 1024 etc ).

你可以下载ATI公司的工具 CubeMapGen ( http://www.ati.com/developer/cubemapgen/index.html ). 这个工具可以很快捷的制作cubemap,下面简单介绍方法.

 

0 选择 "Skybox" 将贴图投射到背景上去方便预览效果.

1 在右侧的绿色栏中,选择"Select Cube Face" 为 +Y (顶视图). 选择 "Load CubeMap Face"选择合适贴图.

2 选择 "Select Cube Face" 为 -Y(底视图), 点击"Load CubeMap Face"选择合适贴图.

3 选择"Select Cube Face" 为+Z (正视图). 点击 "Load CubeMap Face"选择合适贴图

4 选择 "Select Cube Face"为 -Z (后视图). 点击 "Load CubeMap Face" 选择合适贴图.

5 选择 "Select Cube Face" 为 +X (右视图). 点击 "Load CubeMap Face" 选择合适贴图.

6 选择 "Select Cube Face" 为 -X (左视图). 点击 "Load CubeMap Face" 选择合适贴图.

7 现在6张贴图都导入了, 把"Display CubeMap下拉菜单指为"Output".此时中心球体变为黑色,因为你没有任何导出生成

8 点击底部的 "Filter Cubemap"按钮, CubemapGen会花一些时间显示过滤后的贴图在球体上

9 点击顶部的 "Save CubeMap (.dds)" 按钮保存你的cubemap为需要的文件名

你现在就可以把新制作的 .DDS文件的cubemap放到Model Editor中看材质效果了

可重设大小的GUI窗口界面贴图设计

在创建可以重设大小的GUI窗口贴图的时候， 一定要注意遵循几个原则以减少消耗的图元个数。 下面的贴图是制作 "GUI.Frame2" GUI 组件 （BigWorld 中创建 GUI 的 python 代码架构。 这个 Frame2 是一个可以被缩放的GUI窗口边框， 不如工具贴士，聊天窗口之类的。

范例贴图， 使用在可缩放的GUI窗口.frame2_example_source

GUI窗口的效果frame2_example

Frame2 只用了一个图元便完成了整个gui组件。 要达到这样的效果，你需要把所有的边框贴图以特殊的方式组合在一个tga文件中。

第一张贴图时程序调整位图， 也就是展示了如何来设计这个文件 (frame2_example_source), t第二张图是最后的效果展示 (frame2_example.bmp).

这个彩色的图标展示了两件事
1. 边框的哪部分在哪里 (这里特别针对底部那半的资源贴图) - 你可以看见贴图下半部分的四个边界贴图的使用在了，上，下，右，左。
2. 如何让它们平铺呢？ 你看到四个边角只出现了一次，而边界用的贴图是按照贴图大小精确绘制为左右连续的。

这个拼图的最后一部分就是边界的背景了， 这是由位于uv （0.5，0.125） 的单个像素平铺而成的。 注： 就是贴图顶部上方的那个白点。
