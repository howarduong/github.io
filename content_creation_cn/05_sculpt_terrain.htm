调整地面高度

按照以下步骤调整地面高度:

1世界编辑器使用3d笔刷调整地面高度.

点击 工具按钮使用笔刷, - 这个打开Terrain Height 面板, 调整笔刷的大小和强度(控制笔刷作用地面变化的速度).

Terrain Height 面板

每个属性的变化范围可以通过点击 按钮来调整(按钮启动 滑动条参数范围 对话框)

用来设置滑块限度的对话框

2 笔刷按照3d虚线圆圈表示,显示影响区域

视角中笔刷光标显示图

3 调整笔刷大小, 或者使用快捷键 '[' (左方括号是变小) ']'(右方括号是变大) 改变笔刷直径.

快捷键Shift+[和Shift-] 分别增大和减弱笔刷强度. 这个对于笔刷光标显示没有影响. 只影响地面受影响变化的速度

4 刷的时候, 点击鼠标左键在需要的区域就可以

地面在相应部位凸起, 如果你没有发现明显变化,就请增加笔刷强度

Brush Falloff 定义了地面根据笔刷变化的外形, 有三种选择, – Linear线性, Curve曲线 , 和 Flat平面.

地面使用三种笔刷的效果, 从左往右是, flat, linear,curve

你可以撤销刚才的笔刷操作, 使用 工具, 或者快捷键 Ctrl+Z 两种方式都可以撤销多步操作.
可以撤销的是鼠标点击一次的动作, 也就是说,如果你长按鼠标,那么撤销的就是刚在整个鼠标点击并放开的操作.
为了防止丢失过多的信息, 我们推荐不要一笔使用时间过长

5 使用鼠标中键地面下沉.

点击中键,地面下沉

6 使用绝对高度 Explicit Height 可以把地面直接拖到一定高度.

地面使用explicit height ,请参考如下步骤:

A 设定 Explicit Height 值为你需要的高度单位米 – 地面高度可以通过快捷键 Alt 查看

B 按住 Ctrl, 被光标拖动的区域内 - 地面会直接跳到所设定的高度.

Explicit Height设定面板

地面高度到绝对高度

你必须拖动鼠标在所需要的区域滑动来改变高度 - 按住ctrl并点击一次鼠标只影响所点击点的地面高度.

Explicit Height 值, 在叠加时有两种方式: Absolute (直接替换当前高度为设定值); 以及Relative (在当前高度值上添加设定高度).

7 查看地面的方法有三种

A 在 选项 面板下, 显示 列表中, Terrain→勾选Wireframe

面板下, Show 列表

B 点击Chunk Visualisation 工具按钮: (Normal 正常模式), (Chunk borders显示chunk边界), (Pole markers 标记点模式), 或者 (Wireframe 线框模式).

C 使用快捷键 F6 在整个 chunk预览方式下循环切换, 顺序按照工具栏排列顺序

平均笔刷

平均化笔刷是做道路和小径的实用工具. 它通过计算笔刷范围内地面的高度并计算出平均值,并重新赋予高度.

使用平均average笔刷注意;

A 点击 工具按钮,激活地形高度控制面板 Terrain Height;

B 选择平均笔刷

C 调整大小和强度

使用滤镜优化

使用滤镜工具 优化地面,快捷键为 "4" – 启动 Terrain Filtering 面板

1 滤镜按照一定算法对你画的区域做计算, 可以平滑, 锐化,或者给地面添加杂点.

Terrain Filtering 面板

Smooth 平滑滤镜是熨平手动做地面高度的理想工具.Sharpen 锐化工具可以给地面增加小变化. Noise 杂点滤镜可以给地面营造更自然的效果.

2 按步骤使用需要的滤镜.

A 点击 打开 地形高度 面板

B 调整尺寸,强度, 和指定高度到理想数值

C 选择需要的 笔刷.

D 点击 激活 地形过滤器 面板

E 选择需要的滤镜

F 在地面点击使用.

删除地面

剪切工具 按钮, 点击打开地形网格剪切/修补 面板, 可以剪切或者恢复整个地面模型

Terrain Mesh Cut/Repair地形网格剪切/修补 面板

按以下步骤剪切地面:

1 选择剪切 Cut.

2 调整剪切笔刷的大小值 – 以绿色的方框表示

3 升高相机到俯视角度, 可以通过以下方法调整视角:

使用 Q, W, E, A, S, 和 D快捷键调整视角

拖动鼠标调整

点击 用主角视角模式 Orthographic View

4 剪切地面.

点击鼠标按需要的大小剪切.

—或者—

点击并拖动鼠标 – 所划过的区域地面都被剪切.

被剪切后的地面

5 使用修复 Repair 可以通过笔刷补回被剪切的地面模型.
