flora-植物群 体系包括了数以万计的在地表的小物体, 它们丰富了地表的视觉效果, 给游戏添加了活力. 传统的对象包括了草, 石头,小簇的植物, 和花朵. 它们自动随着角色在世界的运动生成,并根据相机的距离淡出.

Ecotype - 生态型, 在此文档中是另一种我们称呼生态系统的方法. 在你的世界里,你可以创建自己的生态型,并联系到相应的地表贴图上使用, 由此当某一贴图被使用时,所关联的生态型也会自动生长在那个贴图覆盖的地表上.

创建你需要的生态型模型

生态性贴图的尺寸和模型面数要求

生态型所使用的是常规的 .visual 文件, 在3ds Max中创建, 并使用 BigWorld'的模型Visual 导出器导出.

生态型是由某一特定贴图相联系的一组不同的模型文件。 例如， 地面贴图 "grass.tga" 可以拥有10个不同的草的模型组合。

 

生态型的3角面定义：

引擎绘制的植物群的三角面总数是根据顶点缓存为基础的， 在 floraflora.xml 文件中设置 <vb_size> 这个特殊的数值表示允许的顶点缓存字节数. 默认的设置是 5,000,000, 此数值还会和美术设定的 flora density 相乘。

Very High Flora 超高密度植物群 乘数为6， 顶点缓存为 30,000,000字节

High Flora 高密度植物群 乘数为 1 ，顶点缓存为5,000,000字节

Medium Flora 中密度植物群 乘数为 0.5 ， 顶点缓存为 2,500,000字节

Low Flora 低密度植物群 乘数为 0.25 ， 顶点缓存为 1,250,000字节

 

生态型三角面数限制:

每个生态型也有一个内部三角面限制， 当然也是基于顶点缓存和flora density数值设置的。

对于每个生态型所适用的三角面可以通过以下算法算出来：

每个生态型适用的三角面数 = ( ( ( vb_size in bytes ) * graphics setting ) / 625 ) / 16 ) / 3

625 = 4x4 植物群板块个数

16 = 每个顶点的字节

3 = 每个三角面有3个顶点

或者用更简单的方式表达; vb_size * graphics setting / 30,000 请看下表.

Flora Detail Level Number of Triangles per Ecotype
Very High Flora 超高密度植物群

每个生态型组的三角面数为960

High Flora 高密度植物群 每个生态型组的三角面数为160
Medium Flora 中密度植物群 每个生态型组的三角面数为80
Low Flora 低密度植物群 每个生态型组的三角面数为40

所以当使用高密度植物群定义整个三角面数量时， 游戏中，每个生态型不可超过160面 每4X4米的板块（一个地形平方）。

作为范例, 如果你的草地生态型包含下面脚本; 

<flora.xml>
  ...
  <ecotypes>
    ...
    <gra_grass_long>
      <texture>   maps/landscape/gra_grass_02.dds       </texture>
      <visual>    grassland/flora/flower.visual </visual> <!-- A 100 triangle flower model -->
      <visual>    grassland/flora/shrub.visual </visual> <!-- An 80 triangle shrub model -->
  ...

那么shrub模型在高密度植物群设置时就不会显示，因为它的加入就超出了160个三角面的限制。

植物群对象定义:

使用高面数的模型并不一定是好效果的必要条件。 每个对象的面数越多，在每4米X4米的单元可以绘制的个数越少。 你可以绘制非常精巧的植物对象，或者也可以像我们的范例一样在地面上得到更多高的覆盖率。

植物群贴图的尺寸:

在一个生态型组中，只能使用一张贴图。

每个生态型的贴图尺寸是通过 floraflora.xml 文件<texture_width> X </texture_width>和<texture_height> Y </texture_height> 标签来定义的。

默认的设置为512x256. 尺寸超过 512x512 是不推荐的。

 

如果你希望有草和花都在名为 greengrass 的生态型中生长的话， 两种模型的贴图都必须画在同一张贴图上。

每个生态型可以拥有多个植物模型, 但是每个生态型只能有一张贴图。

生态型支持 alpha-blending 透明通道渲染技术, 所以请尽量利用它。

下例中给出了一个生态型贴图和它的alpha通道, 由此可见, 包含多个物体的生态型, 只是使用了一张贴图但是要结合合理的UV分布.

植物模型的UV 布局要求

在给生态型模型的UV布局的时候, 很重要的一点就是整个模型的UV必须位于 0,1 范围的边框内. 生态型系统会整合多个模型的贴图到一张大尺寸的图片上, 如果你的UV布局超过了 0,1 的范围. 模型贴图就很可能会被位于大尺寸贴图上, 旁边的贴图所影响.

控制植物模型渲染乱序问题

当创建生态型模型的时候,请保证每个物体或者模型表面的独立性. 请不要在同一个位置上放置多个模型. (请参考下图范例).

即使是不同的flora生态型,也请相对保留模型之间有一定的角度. 因为在生态型计算的时候会在引擎中混合贴图的界限.

游戏设置

Flora.xml

世界编辑器会自动在特定的贴图上生成你的生态形. 所以你必须正确的在游戏中做好设定.

这个设定文件在每个space世界文件夹下,其中有一个 <flora> 标签设定每个世界使用的flora.xml文件位置,这样每个世界可以使用不同的设定.

如果一个世界没有在其设定文件中指定 <flora> 那么他就指定的 flora.xml 默认为 resources.xml 中的设定. 也就是 FantasyDemo位于res/environments 下的文件.

你的 flora 设定文件是在 bigworld/res/resources.xml文件下设定的, 在 <environment> 内 <floraXML>段落中 你可以根据自己的喜好修改你游戏的设定.

<resources.xml>
  ...
  <environment>
    ...
    <floraXML> system/data/flora.xml </floraXML> 
  ...

通过flora定义文件,可以设置当前的生态形(上例中的, system/data/flora.xml), 在标签 <ecotypes>内. 例如你可以设定的ecotype有 grass, arid grass, swamp mud, water verge, dusty path, 等等.

<flora.xml>
  ...
  <ecotypes>
    ...
    <gra_grass_long>
      <texture>   maps/landscape/gra_grass_02.dds       </texture>
      <texture>   maps/landscape/lev_grass_02.dds       </texture>
      <visual>    grassland/flora/gra_grass_long.visual </visual>
  ...

每个ecotype生态型要包含这些信息:

世界编辑器中使用的一系列贴图列表. 也就是将会在这些贴图覆盖的地表上创建生态型.

一个visual标签, 也就是此ecotype生态型需要的模型. 在此列表中的所有模型都是用一张 512x256 贴图.

在添加生态型时,基本都从底部添加 – 这样你就不用重新计算整个世界的生态型了.

上例中, gra_grass_long.visual 的模型就会在整个世界的地表覆盖贴图gra_grass_02.dds的地方生成.

植物群的绘制范围

植物群的绘制使用了半透明混合 (8 位 透明通道) ， 以制造植物群淡出到视野外的效果。 同时我们也使用了大量的非半透明的渲染 （1 位 透明通道）在靠近玩家的植物群上。

这里有一些fantasy demo 中使用的 flora.xml 文件中的设定值 

<AlphaTestRef>			128			</AlphaTestRef>
<ShadowAlphaTestRef>		128			</ShadowAlphaTestRef>
<AlphaTestDistance>		25			</AlphaTestDistance> 
<AlphaBlendDistance>		0			</AlphaBlendDistance> 
<AlphaTestFadePercent>		75			</AlphaTestFadePercent>
<AlphaBlendFadePercent>		50			</AlphaBlendFadePercent>...

植物群绘制的总范围是玩家周围方圆 50 米。 如果使用上面的默认设置， 那么非半透明渲染的模型会在从玩家向外25米的范围内绘制。 同时使用了半透明通道的模型会在50米范围内绘制.
<AlphaBlendDistance> 是表示从最外围50米处向内的距离差。所以当默认值为0时，表示整个区域从0点开始一直绘制到50米处。
<AlphaTestDistance> 定义了由玩家开始向外延伸的绘制非透明模型的距离。 当数值为25时那么绘制范围就是以玩家为中心的方圆25米范围。

给植物群一个自然的疏密分布

植物群噪点

诸如花草之类的植物群并不会在世界中整齐规则的生长. 而已有疏有密.为了模拟这个效果, 我们添加了杂点设置, 在<generator>标签下, 看下图: 

<flora.xml>
  ...
  <ecotypes>
    ...
    <gra_grass_long>
      ...
      <generator> chooseMax
	<fixed>
		<value> 1.1 </value>
	</fixed>
        <noise>
          <frequency> 0.15 </frequency>
          <generator> visual
            <visual> flora/dry_grass/flower_3_tris_stem_1_tris02.visual    </visual>
            <visual> flora/dry_grass/flower_3_tris_stem_1_tris.visual      </visual>
          </generator>   
        </noise>
        <noise>
          <frequency> 0.8 </frequency>  
          <generator> visual
            <visual> flora/dry_grass/grass_upsidedown_2_tris.visual        </visual>    
            <visual> flora/dry_grass/grass_upsidedown_1_tris.visual        </visual>    
            <visual> flora/dry_grass/grass_upsidedown_1_tris02.visual      </visual>
            <visual> flora/dry_grass/grass_upside_upsidedown_2_tris.visual </visual>
            <visual> flora/dry_grass/grass_3_tris.visual                   </visual>
          </generator>
         </noise>   
         <noise>
           <frequency>  4.0 </frequency>  
           <generator> visual
             <visual> flora/dry_grass/grass_upsidedown_1_tris02.visual      </visual>
             <visual> flora/dry_grass/grass_upside_upsidedown_2_tris.visual </visual>
             <visual> flora/dry_grass/flower_3_tris_stem_1_tris02.visual    </visual>
             <visual> flora/dry_grass/flower_3_tris_stem_1_tris.visual      </visual>
           </generator>
         </noise> 
  </generator>
       ...

下面的图标解释了上面的noise混合噪点的生成原理.

<generator> 标签设定选择最大值"choosemax" 在 <fixed> 设定值以上的模型来绘制植物对象。

所以在右图的蓝色表示没有绘制植物群， 而其他的颜色表示其他相应的模型的布局.

如何使用 weight 权重标签保持绘制的道路上没有植物群

上面介绍的早点设置有时会导致你的植物群生长到你已经定义为 <empty> 生态型的区域中去。 通常表现为在道路和小径上生长了植物群。

这个问题可以通过使用 <weight> 标签来解决， 这个标签是在文件 material_kinds.xml 中的位于 bigworld\res\system\data\material_kinds.xml) 

<kind>
		<id>	9	</id>
		<desc>	Dirt	</desc>
		<sound> dirt    </sound>
		<weight>	1.0	</weight>
		<help> Hard crunchy snow. </help>
		<sfx>	sets/global/fx/sfx/sfx_pchang_dirt.xml </sfx>
		<terrain> maps/landscape/path01 </terrain>
		<terrain> maps/landscape/path02
		<weight>	4.0	</weight>
		</terrain>
		<terrain> maps/landscape/path03 </terrain>
</kind>

想要了解 <weight>标签的工作方式，首先要了解 Texture Blend Maps 纹理混合贴图分辨率 和 Flora Blend Maps植物群混合贴图分辨率

Texture 和 Flora Blend Maps:

地面贴图的笔刷是根据创建世界时的 Texture Blend Map纹理混合贴图分辨率 设置来定义的。

引擎使用了一个近似的混合贴图， 植物群混合贴图来定义那些生态型会在指定区域生长。 这个分辨率常在高级地形时通常为纹理混合贴图分辨率的一半， 在简单地形时为一致。

上面提到的<weight> 权重标签的值加乘了所赋予的植物群混合贴图的值。 所以当我给贴图 path02.tga 一个4.0的权重值， 那么它的最后强度是植物群混合贴图上其他贴图的4倍， 防止了其他植物扩展到它的区域。

注: 更多关于 material_kinds.xml 文件的使用方法请看 地形材质类型章节

各类 xml 标签

还有一些在flora.xml文件中很有用的标签,在此介绍一下.

<vb_size> 这个标签控制顶点缓存容量， 也就是定义根据尺寸一次性可以生成多少的flora对象， T数值越大产生越多的flora， 但是会影响到游戏效率。L

<flex> 0.0 </flex> 定义游戏中风对应生态型的作用. 0 = 没有效果, 1.0 = 完全作用.

<density> 0.8 </density> 定义生态型在地面生成的频率, 数值范围0到1。 这个数值并不控制flora生成的总量， 只是在最大量 1.0 的范围上做百分比， 如果要增加总数，请用<vb_size>

<scaleVariation> 0.7 </scaleVariation> 应用为一个参数作用在生态型的尺寸上, 定义一个随机缩放的范围. 例如, 0.5的数值, 会使得一个原本尺寸为1的物体 在游戏中生长时从 0.5 到1.5 的大小变化

<weight> 5 </weight> 这个标签是在 material_kinds.xml 文件中的， 你可以在 bigworld\res\system\data\material_kinds.xml 中找到它， 虽然不包含在 flora.xml 文件中， 但是它可以影响flora在地表生长的方式。 所有的生态型都有一定的衍生量， 比方说， 某种生态型会扩展到其他贴图的区域， <weight>的值可以防止其他生态型对自身的影响。数值越高其他生态型衍生到此组生态型贴图范围的可能性越低。在绘制道路时非常有用，可以防止边上的草地，长到路面上。

美术和游戏效率相关提示

在创建生态型时, 请注意以下几点:

每屏渲染多少像素点直接影响游戏的表现 –对于模型顶点数目是可以忽略不计的.

然而,请注意你的小物体不要含有太多的像素信息, 例如,不要创建那些半人高的草, 除非你很清楚自己的计划, 自己在做什么.

细节物体的颜色非常重要.

你总是希望它们可以没有明显的接缝, 所以要尽量避免物体接触地面时有明显的接缝. 所以要保证每套flora的颜色和地面贴图的颜色非常相似.

显然, 你可以在模型贴图的上半部分添加丰富的颜色,因为它们并不与地面接触.例如, 花茎的颜色要和地面贴图一致, 而花瓣的颜色可以明亮而大胆.

也可以在你贴图alpha通道的底部淡淡的加一层黑色,也可以帮助弱化地面和flora的接缝,也可以更好的过渡植物和地图的颜色.

丰富的变化也很重要的, 所以请尝试在一个ecotype中创建更多的模型文件

(比如, 一个512x<256的矩形贴图上).对草的物体小小的变化会大大增加地表生态型的真实效果

因为每4X4米的地面内可以有32个三角面, 所以如何创建细节对象完全取决于你的设计.

例如,你可以创建一个32面的蕨类植物, 在地表上它的生长会很稀疏,而你也可以创建一个2面的草, 则同样的地表就会有更茂密重叠的地面了.
