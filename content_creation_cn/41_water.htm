在世界编辑器中添加水

所有的水在同时渲染的时候要保证在同一Y值上, 即统一水平面高度. 如果不统一, 那么它的反射计算速度就会很慢

按下步骤在世界中添加水:

1 在 资源 面板下, 选择Misc文件夹

2 选择 water.xml– 文件实际路径为 bigworld/res/helpers/misc

3拖动文件到理想位置放开.

水可以像其他物体一样的缩放或拉扯, 除了旋转有所不通, 因为它只能围绕Y轴旋转.

目前水的深度被限定在10个单位内.

水表面

水的效果是通过一个fx材质实现的,其中包括按照菲涅耳定律对目标贴图做反射和折射.

涟漪是根据波纹贴图 属性中指定的法向贴图-normal map来定义的. 且动画是由两组参数控制的.

默认的贴图是Bigworld\res\system\maps\waves2.dds.

如果使用模拟选项启用, (通过使用 use simulation true 属性), 那么水面会结合涟漪贴图,表现出涟漪和光影互动变化.

alpha的值是更具每个顶点的高度来定 (高度值根据点对地面相对高度定义) 用来淡出水面边界. 要启用此效果需要将属性在边界上使用alpha设定为true.

水的属性

作为水面的模型是自动生成的, 并根据它和地表的高度,计算水的边界到地面的渐变效果. 淡出效果使用的是Alpha透明值, 并可通过对 use edge alpha 属性设置关闭. 贴图通过波纹贴图属性定义,上节有描述.

推荐把水的尺寸定为为网格大小的倍数.

我们不建议把多个水物体做相邻的安置, 除非他们的Y轴高度值一致.

水的使用模拟默认是开启的, 并且可以通过下拉菜单false关闭.

波纹动画是根据动画贴图来制作的, 可调整的属性请参考下表:

属性
wind speed 风速
wave scale波纹大小
scroll speed 1 漩涡速度1
scroll speed 2 漩涡速度2

关于水的属性描述请参考下表:

属性 Description

consistency粘稠度

表面仿真模拟扩展衰变, 1值设定没有涟漪衰变.
fresnel constant-菲涅耳常熟 定义最小的反射量.
fresnel exponent-菲涅耳指数 调整水平面和镜头位置夹角的变化.
mesh Size-网格大小 mesh表面的三角面大小.
高数值则水表面使用的mesh少, 底数值增加了面数.
建议mesh size 和整个水的size 成数量比. 为了检查这个属性的效果,你可以选择 General Options 下的 Show 组下勾选 Terrain→Wireframe.
orientation-方向 水面的旋转
position-位置 水面的位置
reflection strength-反射力度 水波动画反射的扭曲度
reflection tint- 反射色彩 水面反射的颜色设置
refraction Strength-折射力度 水波动画折射的扭曲度
refraction tint-折射色彩 水面折射的颜色设置
scroll speed 1-卷轴速度1 两张影响水波动画的贴图中第1张的坐标移动速度
scroll speed 2-卷轴速度2 两张影响水波动画的贴图中第2张的坐标移动速度
sim cell size-模拟单元大小 表面互动涟漪的尺寸
数值越大,涟漪越明显. 因为贴图会在一个大的区域做伸展. 小数值增加涟漪的细节,但是影响的水面范围小.
size-尺寸 水面的尺寸.
sun Power-阳光指数

对于反射高光的亮度设置,数值越高,高光的范围越小越锐利.

sun Scale-阳光强度 对于反射高光的范围大小设置, 数值越大,高光范围越大.
fade start depth-开始渐变深度

对于深度变化的起始值.

foam intersection-泡沫交叉 在哪个深度开始起泡沫, 小的数值会一直覆盖到深层的区域, 大的数值使得泡沫只在浅水区出现.
foam multiplier-泡沫乘数

对泡沫贴图强度设置,大的数值,泡沫强度越明显
surface smoothness-表面光洁度 水面的波动动画强度, 大于1则表面没有波动影响, 0表示完全影响.
foam tiling-泡沫平铺

泡沫贴图UV大小变化值,越大贴图重复率越高,图案越小.
faom texture-泡沫贴图 泡沫贴图路径
texture Size-贴图大小 虚拟的单个面的大小, 和meshsize 很类似, 除了他是虚拟的. 因为它只是作用在表面贴图的尺寸上.
use edge alpha-在边界上使用alpha 水面边界的透明度开关
use simulation-使用模拟 对水面仿真模拟的开关
wave scale-波纹缩放 对每个定义波纹动画贴图的缩放设置 (X value for texture map 2, Y value for texture map 2)
wave texture-波纹贴图 水面波纹的定义贴图.
wind speed-风速 附加在水波纹动画上的速度.
